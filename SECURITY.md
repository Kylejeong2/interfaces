# Security Policy

## Reporting a vulnerability

Please use [GitHub's private vulnerability reporting](https://github.com/Kylejeong2/interfaces/security/advisories/new) for security issues. Do not open a public issue or pull request that reveals an unpatched vulnerability.

Include:

- the affected route, dependency, or configuration
- steps to reproduce the issue
- the likely impact
- any suggested mitigation

You can expect an initial response within seven days. Please allow time for a fix before disclosing the issue publicly.

## Supported version

Security fixes apply to the current `main` branch and the production deployment. Older commits and third-party forks are not maintained.
