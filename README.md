# The AI Interface Museum

A visual history of how humans learned to interact with AI.

The museum follows one chronological timeline from 2011 onward. Entries are selected for adoption and cultural impact first, with technical and interaction novelty as supporting evidence. Distinct product generations are separate artifacts when they introduce a genuinely different interface.

The collection currently spans chat, voice, vision, canvas, code, search, recommendation, ambient computing, audio, video, computer use, agents, autonomous vehicles, and embodied systems.

## Artifact contract

Every artifact includes:

- a release date and product edition
- the interaction and product-layer taxonomy
- a short description of the interface
- what changed relative to its lineage
- why the product mattered
- links to first-party sources or demonstrations
- an archival interface image when a defensible first-party visual is available

Graphic reconstructions are clearly labeled and fill gaps where a suitable archival screenshot has not been cleared or located.

## Development

The site is a single-route TanStack Start application.

```bash
pnpm install
pnpm dev
```

Before committing:

```bash
pnpm lint
pnpm build
```

Product names, marks, and archival imagery belong to their respective owners and are shown for historical and editorial reference.
